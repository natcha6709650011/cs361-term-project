# ระบบจองห้อง CS Thammasat

โปรเจกต์นี้เป็น Frontend แบบ HTML, CSS และ JavaScript สำหรับแสดงข้อมูลห้องและเตรียมเชื่อมต่อระบบจองห้อง

## ไฟล์สำคัญ

- `index.html` — หน้าแรก มีประเภทห้องและห้องแนะนำ
- `script.js` — เรียก API ห้องและสร้างการ์ดห้องจากข้อมูลที่ได้รับ
- `styles.css` — รูปแบบของหน้าแรก
- `guidelines.html` / `guidelines.css` — หน้าข้อปฏิบัติ
- `contact.html` / `contact.css` — หน้าติดต่อเรา
- `room-bor2-308.html` / `room-detail.css` — หน้ารายละเอียดห้องตัวอย่าง
- `components/header-component.js` — สร้าง header เดียวกันให้ทุกหน้า

## การเชื่อม API ห้อง

หน้า Home เรียก `GET /v1/rooms` จากตัวแปร `ROOMS_API_URL` ใน `script.js` และนำข้อมูลไปแสดงเป็นการ์ดห้อง

หน้า Home กำหนดห้องแนะนำไว้ 4 ห้อง คือ 308, 107, 214 และ 106 หาก API ยังไม่มีห้องใด ระบบจะแสดงข้อมูลสำรองใน `index.html` แทน เพื่อให้หน้าเว็บไม่ว่างเปล่า

## สิ่งที่ต้องมีจาก Backend ต่อไป

1. เปิด CORS ให้ Frontend เรียก API ได้
2. API รายละเอียดห้องตาม `room_id`
3. API ตรวจช่วงเวลาว่างและสร้างคำขอจอง
4. API ดูสถานะและอนุมัติคำขอจอง
